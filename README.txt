Для перехода на страницу микросервиса UserSerivice необходимо зайти на url http://localhost:5111/swagger/index.html
Для перехода на страницу микросервиса ProductService необходимо зайти на url http://localhost:5077/swagger/index.html

На странице микросервиса UserService необходимо пройти регестрацию через end point registration, после регистрации на вашу почту будет выслана ссылка для подтверждения почты, при переходе на которой ваша почта будет подтверждена и вы сможете по залогинится.

После успешного логина будет выдан jwt, который необходимо ввести в поле Authorize в формате Bearer Jwt,
так же в таком формате необходимо ввести и в ProductService, для работы с данным микросервисом.

В случае если вы забыли пароль необходимо нажать "forgot password", и ввести зарегистрированую почту, на нее придёт ссылка для сброса пароля.

При удалении пользователя он становится неактивным и все его продукты так же становятся не активными, для активации пользователя необходимо нажать "сделать пользователя активным" и ввести зарегистрированный email.
